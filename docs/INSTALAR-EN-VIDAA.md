# Instalación de prueba en Hisense VIDAA

## URL web

1. Publica esta carpeta en una URL HTTP/HTTPS accesible desde la TV.
2. Abre el navegador de la Hisense.
3. Escribe `hisense://debug`.
4. Introduce:
   - App Name: `TV EN VIVO`
   - App URL: la URL donde está publicado `index.html`
   - Resolution: `1080`
   - Thumbnail/Icon: URL pública de `assets/icon.svg` si el modelo la acepta.
5. Selecciona `INSTALL`.
6. Sal con Exit y abre Apps.
7. Busca `TV EN VIVO`.

## Control remoto

- Flechas: mover foco.
- OK/Enter: seleccionar.
- Back/Return: cerrar panel o volver.

## Reproducción

Los campos `stream` están vacíos a propósito. Deben rellenarse sólo con transmisiones que tengas autorización para usar.
