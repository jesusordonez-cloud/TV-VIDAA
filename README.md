# TV EN VIVO para Hisense VIDAA — v1.0

Aplicación web para Hisense VIDAA, diseñada para pantalla 16:9 y navegación con control remoto.

## Funciones
- Inicio tipo Smart TV.
- Navegación por D-pad / control remoto.
- Canal destacado.
- Recomendados y filtros por región.
- Favoritos persistentes.
- Buscador.
- Panel de configuración.
- Guía TV inicial.
- Estado de red y reloj.
- Reproductor HTML5 preparado para una URL de streaming autorizada.
- Diseño 1080p adaptable a resoluciones menores.

## Estado
La interfaz base es funcional. La siguiente fase será conectar streams legales/autorizados y una fuente EPG real, y validar la reproducción en el modelo exacto de Hisense/VIDAA.
